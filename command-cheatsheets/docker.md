# Docker Commands

## Containers
dps       → docker ps
dpa       → docker ps -a
dst       → stats

## Images
di        → images

## Logs / Exec
dl        → logs
dlf       → follow logs
dex       → exec -it

## Build / Run
db        → build
dr        → run
drm       → rm
drmi      → rmi

## Compose
dcu       → compose up
dcud      → compose up -d
dcd       → compose down
dcb       → compose build
dcl       → compose logs
dclf      → follow compose logs

## Cleanup
dclean    → system prune
dcleanf   → prune all (danger)
