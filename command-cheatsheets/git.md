# Git Commands

## Status
gs        → git status -sb
gss       → git status

## Logs
gl        → oneline log
glg       → graph log (all branches)
gla       → pretty graph log

## Branch
gb        → list branches
gbv       → branches with upstream
gbd       → delete branch

## Checkout / Switch
gco       → checkout
gcob      → checkout new branch
gsw       → switch
gswc      → switch new branch

## Commit
ga        → add .
gaa       → add -A
gc        → commit
gcm       → commit -m
gca       → amend
gcan      → amend (no edit)

## Fetch / Push
gf        → fetch
gfa       → fetch all + prune
gpo       → push origin HEAD
gpm       → push origin main

## Rebase
grb       → rebase
grbi      → interactive rebase
grbc      → rebase continue
grba      → rebase abort

## Diff
gd        → diff
gds       → diff staged
