# Kubernetes Commands

k         → kubectl

## Get
kgp       → get pods
kgs       → get services
kgd       → get deployments
kgn       → get nodes
kgi       → get ingress

## Describe
kdp       → describe pod
kdd       → describe deployment

## Logs
kl        → logs
klf       → follow logs
klp       → previous container logs

## Exec
kex       → exec -it
ksh       → shell
kbash     → bash shell

## Context / Namespace
kctx      → use context
kctxs     → list contexts
kns       → set namespace
knsa      → list namespaces

## Rollouts
kro       → rollout status
kru       → rollout undo
